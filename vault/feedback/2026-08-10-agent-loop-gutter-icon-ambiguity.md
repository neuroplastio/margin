# Gutter icon ambiguity

Feedback, 2026-08-10, from the maintainer's agent loop.

Not obvious from the TUI, `--help`, or `margin skill` what a gutter icon on a
block actually means — cursor/selection position vs. an active comment marker
vs. a reviewed/flagged mark look similar enough that even reading the docs, the
agent gave the wrong answer on the first try. Might be worth a visual
distinction or a line in `--help` naming what each glyph means.
