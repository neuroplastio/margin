# Markdown rendering inside block quotes and list items is broken

Markdown bold syntax (`**`) is not being rendered correctly when inside a block quote or a list item. Instead of rendering as bold text, the literal asterisks are being displayed on the screen (e.g. `**Open question.**` and `**Week 1**`).
