## What changed

Addressed maintainer feedback in `vault/feedback/2026-08-09-deleted-comments-and-code-hscroll-feedback.md`:

1. **Preserve Deleted Comment Body & On-Disk Shape:**
   - `deleteComment(i)` (`internal/review/document.go`) no longer wipes `c.body`. Deleted comments keep their body text in memory.
   - `marshalThread` (`internal/review/store.go`) writes `## author — timestamp [deleted]` in the comment header line and saves the body text intact.
   - `parseComments` (`internal/review/store.go`) parses the `[deleted]` header marker and restores legacy tombstone markers (`*deleted*`) as deleted empty body comments for backward compatibility.

2. **Immediate Delete / Restore Toggle (`D`):**
   - Removed delete confirmation prompt (`confirmDelete`) from `thread.delete` command execution (`internal/review/review.go`).
   - Pressing `D` on an active comment or thread immediately marks it deleted.
   - Pressing `D` on a deleted comment or thread immediately restores it (`c.deleted = false`).
   - Status bar reports "comment deleted" / "comment restored" or "thread deleted" / "thread restored".

3. **Rendering Deleted Comments:**
   - In `appendComments` (`internal/review/review.go`), deleted comments display their actual body text rendered in dimmed style (`dimStyle`) rather than substituting the literal string `"[deleted]"`.
   - The comment header line continues to display `[deleted]`.
