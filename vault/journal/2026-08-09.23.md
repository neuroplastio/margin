## What changed

Addressed feedback "Focus Retained on Comment Exit" in `vault/feedback/2026-08-09-additional-ux-and-cli-feedback.md`:

- Updated `dismiss()` (`internal/review/review.go`) so that when the composer exits without an explicit click-away (`pendingOpen == nil`), focus (`m.at.comment`) lands directly on:
  - the newly created comment (index `len(t.posted) - 1`) when a new comment is posted.
  - the edited comment (`target`) when an existing comment is updated, draft-saved, or discarded.
- When focused on a comment, pressing `e` immediately re-edits that comment without requiring extra navigation (`l` / mouse click).
