# 2026-11-05.4 — the search prompt on hotty-surf (leg 3)

Kind: felt (the prompt's look on a host and in cells).
Task: porting margin to hotty-surf, leg 3 (vault/knowledge/hotty-surf-port.md).
Commit: (this one)

## What changed

- The `/` prompt is a hotty-surf component: `Search` (search.go) and
  `search.surf`: a rule, then "/", a bare `field` and the count. It is a
  dense surface on a host and `cells.Renderer` lines elsewhere.
- Enter, esc and ctrl+c are margin's (`Surface.Program`), so the field gives
  them back. Typing on a host is the host's field, which reaches the model as
  an input event (`Search.Typed` → `searchDrafted`); in cells the keys go to
  the renderer (`surfHost.cellsKey`, `cellsPaste`).
- The prompt opens empty: its component is made when it opens and dropped
  when it closes (`m.search`).
- In cells the field has the terminal's cursor, a bar where the renderer's
  caret is (the renderer reports it, `surfHost.caret`); before, none showed.
- `surfHost` holds the cells renderer (`lines`, `cellsKey`, `cellsPaste`);
  the footer uses it too.
- hotty-a2ui no longer draws the search prompt.

## A finding

One Surface has one consumer. `view()` drew the prompt's cells to count its
rows even where a host placed it, and the cells renderer's `Update` took the
surface's diff, so the host never got the count's change. The cells are
drawn now only where there is no host (`searchRows` is the prompt's height
on a host). Recorded in findings.md.
