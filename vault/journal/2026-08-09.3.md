## What changed

Added a command palette interface for the document view, wiring up the UI for the previously built command registry logic.
- **Trigger**: Press `:` to open it.
- **UI Treatment**: It renders at the bottom of the review pane, replacing the default status line and progress bar while it is open. It takes up to 9 rows (7 for listed items + 1 for input + borders).
- **Filtering**: Type to filter (using the `matchCommands` and `paletteRows` logic). Use `<Up>` and `<Down>` (or `ctrl+j`, `ctrl+k`, `tab`) to navigate the matches. `Enter` to run. `Esc` to close.
- **Appearance**: The active item highlights with the focus bar. The document is not dimmed because the palette lives cleanly at the bottom, mimicking a traditional vim command line while supporting a full ranked list display.

## Verification

`make check` and `make test-race` both pass.

## Demo

```bash
go run ./cmd/margin testdata/sample.md
```

1. Type `:`. The palette opens at the bottom.
2. Type `mark`. The palette filters to `mark` commands.
3. Use `<Down>` and `<Up>` to navigate.
4. Press `Enter` to run the selected command.
5. Press `:` again, and press `Esc` to close it without running anything.
