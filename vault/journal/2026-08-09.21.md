## What changed

The feedback asked to shift the `.margin` directory location from being placed inside subdirectories (e.g. `testdata/`) to the project root (detected via `.git` or `.margin` anchor), with relative `docPath` preserved.

- `resolveReviewRoot(path string) (root, docPath string)` added in `internal/review/store.go`.
- `resolveReviewRoot` walks up parent directories starting from `path`'s directory to find `.git` or `.margin`. If found, that directory becomes `root` and `docPath` is `path` relative to `root`. If no root marker is found, it falls back to the current working directory.
- `Run` in `internal/review/review.go` updated to call `resolveReviewRoot(path)` instead of `filepath.Dir(path), filepath.Base(path)`.
