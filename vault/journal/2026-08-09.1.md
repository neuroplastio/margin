# 2026-08-09.1 — THREAD-04: What deletion looks like and what confirms it

## What changed

Added the `thread.delete` command, bound to `D`.
It deletes the focused comment if a specific comment is selected in an expanded thread, or deletes the whole thread otherwise.

To prevent accidental deletions, especially since an agent's reply might be in the thread, the command requires confirmation. Pressing `D` once prompts "Press D again to delete comment" (or "delete the whole thread") in the status line and sets a `confirmDelete` state. Pressing `D` a second time actually applies the tombstone and saves to disk. Pressing any other key clears the confirmation state.

Visuals for a deleted comment:
- The comment body is replaced with `[deleted]`, styled with `dimStyle`.
- In the collapsed summary, if the first comment is deleted, it shows `author · [deleted]`.

## Demo

```bash
go run ./cmd/margin testdata/sample.md
```

1. Navigate to a block with an existing thread.
2. Press `D`. See the prompt "Press D again to delete the whole thread".
3. Press `j` or any other key. The deletion is canceled.
4. Press `D` and then `D` again. The thread is deleted (all comments tombstoned).
5. Expand the thread (if not already) and check the rendering. The deleted comment should show `[deleted]` in place of its text.
