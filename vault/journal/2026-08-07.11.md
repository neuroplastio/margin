# 2026-08-07.11 — CMD-04: focus-sensitive listing and the titled target

Kind: mech
Task: CMD-04 (from the command-palette feedback's suggested split — see
`vault/journal/2026-08-07.6.md`)
Commit: (this one)

## What changed

CMD-02 answered requirement 1 (rank by query). This leg answers requirement
4: "It offers what applies to what is focused, and names the target... the
difference between 'Delete' and 'Delete — comment by agent' is the
difference between confidence and a guess." Still no UI, no `:` key —
`paletteRows` and `paletteTitle` (`internal/review/palette.go`) are the whole
surface, callable and testable with nothing wired into the model or
`handleKey`.

**Applicability.** `paletteRows(m *model, cmds []command) []paletteRow`
filters `cmds` down to the ones whose `Applicable(m)` is true for the
model's current focus, in registry order — exactly CMD-01's `Applicable`
field, which existed but was unused metadata until now. A command that does
not apply is dropped entirely, the same rule CMD-02 already applies to a
query that matches nothing.

**The titled target.** `command` gains a new field, `Target func(m *model)
string` — nil for a command with no focus-specific target (`move.*`,
`review.export`, `app.quit`: these act the same no matter where focus sits),
and set for the three that do:

- `comment.new` → `commentTarget`: the kind of block focus sits on
  ("heading", "paragraph", "block").
- `comment.edit` → `editTarget`: mirrors `editFocused`'s own precedence
  (review.go) without its side effects — the focused posted comment by
  author ("comment by agent"), else an unsubmitted reply ("draft reply"),
  else a posted comment with an edit in progress. `Applicable` only requires
  a thread to exist, which does not guarantee one of those three actually
  matches (focus can sit on the thread entry itself with nothing more
  specific going on) — in that case `editTarget` returns `""`.
- `mark.reviewed` / `mark.flagged` / `mark.cycle` → `markTarget`: "block" for
  a single paragraph, "section (N blocks)" on a heading. This reuses a new
  `sectionLabel` helper (review.go) factored out of `toggleMark` and
  `cycleMark`, which built the identical string inline before this leg —
  so the palette's title and the status line the key itself leaves behind
  can never say two different things about the same action.

`paletteTitle(c command, m *model) string` combines the two: `Description`
alone when `Target` is nil or returns `""`, `Description + " — " + Target(m)`
otherwise.

There is no delete command yet — THREAD-03 is blocked on Q-0002 — so the
feedback's own example ("Delete — comment by agent") is illustrated with
`mark.reviewed` on a heading instead ("Mark reviewed — section (3 blocks)").
`Target`'s shape does not depend on which command has it; whichever lands
first, delete included, reads it the same way.

## What this deliberately does not do

No `:` key, no rendering, no query. `paletteRows` says nothing about a typed
query — that composition (focus-filter, then rank, or the other way, or does
it matter) is CMD-03's to decide once there is a screen to judge it against.
