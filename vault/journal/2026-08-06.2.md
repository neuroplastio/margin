## What changed

`margin FILE.md` now opens a real document.

`parse.go` turns markdown source into the flat block list the model already
worked against. Only top-level nodes become blocks — nesting is a rendering
concern, and a reviewer comments on "that paragraph", not an inline span.
Headings carry their level and text; paragraphs are collapsed to one line for
re-wrapping to the measure; everything else — lists, fences, quotes, tables —
becomes a `blockRaw` rendered verbatim, because there the indentation and line
breaks *are* the content.

Every block carries its byte range, which ID-01 will need to stamp ids back into
the source.

The seeded document did not disappear — it became `seedModel()`, the fixture the
existing 24 tests assert against, so nothing regressed while the real path was
added.

## Notes

Two things deliberately left undecided, both now on the board:

- **Heading levels are parsed but unused** (RENDER-05). `#` and `###` render
  identically. A terminal has no font sizes, so this is a real decision —
  indentation, rules, colour weight, a visible prefix — and not mine to make.
- **Inline markup is raw** (RENDER-06). `**bold**` and `` `code` `` show as
  source. On a real document this is a large share of the remaining
  reading-comfort gap.

Anchors are currently a content hash. That is honest but interim: the entire
point of anchoring is surviving a rewrite, and a content hash by definition
cannot. ID-01 replaces it with ids stamped into the source. Until then, threads
attach within a session but will not survive the agent rewording a block.

Two gotchas worth knowing:

- `ast.Node.Lines()` **panics** on inline nodes ("can not call with inline
  nodes"). The extent walk has to filter on `c.Type() == ast.TypeBlock`.
- goldmark's `Lines()` covers a node's *content*, so a fenced block's range
  excludes the ``` fences and a heading's excludes the leading `#`. Fine for
  anchoring and rendering; ID-01 will need to widen to line boundaries.

Judge:

- Headings all look the same — how much does that hurt while scanning? What
  should distinguish them (RENDER-05)?
- `**bold**` and backticks show as source. How distracting is that in practice
  (RENDER-06)?
- Lists and code fences render verbatim in a different colour. Does that read as
  "a block of its own", or as noise?
- `j`/`k` through it, `c` on a paragraph, `r` on a few blocks — does the loop
