## What changed

Addressed maintainer feedback in `vault/feedback/2026-08-09-deleted-comments-and-code-hscroll-feedback.md`:

1. **Horizontal Scroll for Code Blocks (`blockCode`):**
   - Code blocks do not wrap lines to measure `w`.
   - `scrollCodeLine` skips `offset` visual columns while preserving ANSI highlighting (chroma styles), clipping output to at most measure `w` visual columns.
   - When focus sits on a code block (`blockCode`), pressing `l` (or `right`) scrolls the block right by 4 columns (`m.scrollCode(4)`), and pressing `h` (or `left`) scrolls left by 4 columns (`m.scrollCode(-4)`).
   - Scroll offsets are tracked per block anchor in `m.codeScroll[anchor]` and bounded between `0` and `maxLen - measureWidth`.
   - When focus is not on a code block (or inside a thread comment), `l` and `h` continue to dive into and surface from comment threads (`m.dive()` / `m.surface()`).
