## What changed

The maintainer's agent loop misread the gutter: on a block with a thread, the
collapsed thread's dim `│` marker and the reviewed/flagged mark's `│` rule were
the same glyph, two columns apart — "a conversation lives here" was
indistinguishable from "reviewed or flagged", and nothing in `--help` or
`margin skill` named any of it.

- **The thread marker is now `▸`, not `│`** (`threadLines`, `review.go`). A
  collapsed open thread reads as a right-pointing triangle — the point is the
  dive `l`/`enter` performs on it — and is distinct from the mark rule's `│`,
  the focus bar's `▌` and the resolved thread's `✓`. Same width, same dim, so
  nothing moves.
- **`margin --help` gains a Gutter legend** naming every glyph in the column —
  `▌` cursor/selection, `│` reviewed (green) / flagged (orange), `·` partly
  marked, `▸` comment thread, `✓` resolved — so the answer is one `--help`
  away, the literal ask.
- **The README carries the same paragraph** after the Keys table.
- **`margin skill` gains a "Reading the human's screen" section** — the
  feedback named the skill document as one of the three places that did not say
  what a glyph means, and an agent asked to describe the screen reads it there,
  pointing at `--help` as the same legend.

**What I chose and rejected:** a visual distinction *and* the documented legend
(the feedback offered either; the collision is real and the docs were the
"even reading the docs" complaint, so I did both); `▸` for the thread over a
`●`/`◆` dot (the triangle names the dive that opens the thread, and nothing
else in the gutter uses a pointing shape) and over dimming the mark rule
further (marks are settled as a vertical rule — 2026-08-09.17 — and changing
*them* would unsettle the more important signal); the legend in the root
`--help` rather than only the README (the root help is what an agent actually
reads first). Rejected: raising a question — the feedback offers the remedies
and everything here is layout, rename-cheap.

Judge:
1. **The thread marker reads apart** — with a reviewed block (green `│` rule)
   that also carries a collapsed thread, does the `▸` read as "a conversation
   is here" at a glance, or does it still blur with the mark rule? Is `▸` the
   right shape, or would a filled dot / `⁞` / nothing (bare dimmed text) read
   better?
2. **The legend's place** — is the Gutter block in `--help` the right depth
   (five lines), and is the skill document's "Reading the human's screen"
   section something an agent asked to describe the screen would actually find?
3. **Colours worth naming?** — the legend says "reviewed (green) / flagged
   (orange)" in words. On screen the colours carry it; is the wording right, or
   does it need the actual colour names anywhere they cannot be shown?

(What I chose: `▸` over the old dim `│`, and the legend in all three places.
What I rejected: changing the mark rule's `│`, a separate glyph for focus vs
