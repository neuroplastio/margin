# 2026-08-09.6 — SCROLL-03 (Mouse wheel)

`[felt]`

## What

Added mouse wheel scrolling (`tea.MouseWheelMsg`).
- Handled `tea.MouseWheelMsg` in `model.Update`.
- Scrolls the document viewport directly (via `m.scroll`), bypassing `clampScroll`'s snapping so focus intentionally stays left where it is. This makes the mouse wheel act exactly like a wheel normally behaves in a pager or browser.
- If the wheel is scrolled while hovering over an open composer, the scroll event is routed to the child `nvim` via `sendMouse` instead, allowing you to scroll through the comment text independently.

## Demo

1. Run `make run` or `margin some-large-doc.md`.
2. Ensure you have enough text to scroll.
3. Scroll the mouse wheel up and down. Focus should stay where it is, and the view should shift.
4. Press `c` to open a comment composer on a block, type some lines.
5. Move your mouse pointer over the composer window and scroll the wheel. The comment should scroll instead of the document.
