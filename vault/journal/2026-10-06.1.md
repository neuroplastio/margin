# 2026-10-06.1 — a seed beside the launcher: install.sh and margin-bin

Kind: mechanical (the script is tested end to end against a test channel;
the PKGBUILD is rendered and packaged by hand; the AUR job's first real run
is the next release).
Task: maintainer direction — port kubecom's launcher + seed packaging and
its install script to margin (D22).
Commit: (this one)

## What changed

- **`install.sh`**: `curl … /install.sh | sh` checks the newest stable
  release against the pinned key, installs `margin-launcher` as
  `~/.local/bin/margin` and seeds `~/.local/margin` with the complete
  margin, so the first run needs no network. `MARGIN_CHANNEL`,
  `MARGIN_COMMIT`, `MARGIN_BINDIR`, `MARGIN_FORCE`; `MARGIN_URL` and
  `MARGIN_SIGNERS` for a test or a mirror.
- **`packaging/aur/`**: the `margin-bin` PKGBUILD template — the launcher
  as `/usr/bin/margin`, the seed at `/usr/lib/margin/bin/margin`, depends
  on `neovim` — and `publish.sh`, which renders it from a release's four
  linux files, builds it with makepkg, and pushes it (ported from
  kubecom's, names changed).
- **`release.yml`**: an `aur` job on a tag after publish, in an Arch
  container; skips when `AUR_SSH_PRIVATE_KEY` is not set.
- **`margin-launcher --launcher-version`** names the launcher; the
  README says which of the two versions is which.
- `testchannel.PublishAll` publishes several artifacts as one build.
- **README**: Install leads with the script and the AUR, then the manual
  verify-and-install path.

## Tests

- `TestInstallScriptDropsTheLauncherAndSeedsTheHome`: a release of
  margin + margin-launcher (built `-tags updatetest`) on a test channel;
  the script installs into an empty home; the installed margin answers
  `--version` with its server a closed port, and `--launcher-version`; a
  second install keeps the home's build, `MARGIN_FORCE=1` replaces it; a
  build whose binary was altered after signing installs nothing; the
  release key the script pins refuses the test channel. A mutation that
  skips the sha256 check fails it. Skips without curl or ssh-keygen.
- The PKGBUILD rendered with fake sums, sourced, and `package()` run
  against empty files: `usr/bin/margin`, `usr/lib/margin/bin/margin`.
- actionlint reports nothing on the workflow.
