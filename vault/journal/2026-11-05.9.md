## What changed

1. **Compact, not dense.** The footer, the search prompt and the palette are
   hotty-surf's default Compact now: IBM Plex Sans, where I had chosen dense,
   which is the terminal's mono. My reason for dense was that margin places a
   surface over a whole number of cells, and dense rows are cells. That
   isn't enough to make the chrome mono: it changed margin's look from the
   a2ui kit's sans, where "the same look as the rest of the stack" asked for
   it. Compact rows are a cell and a little air (an item's 4 px of padding
   each side, a rule's 4 px margins), so margin counts the palette's rows on
   a host from the host's cell size (`Caps.CellCSS`, `paletteHostHeight`):
   whole rows, the field under the commands. The footer and the search prompt
   fit the rows they had. A sans is narrower: the footer's six hints now fit
   at 897 with a status message, where mono caps cut them (the fit-start
   reshoot will count it).
2. **Keys.** `move.scrollDown` is `J`, a capital: shift+j. `surfKey` turns
   margin's raw keys into myelin's names (`J` → `shift+j`, `esc` → `escape`,
   `pgdown` → `page_down`, `yr` → `y r`, `up` → `arrow_up`, ` ` → `space`),
   so the palette says `⇧+J` and `J` is only `j`. The palette showed `J` for
   both because the raw `J` went to surf as is, and a key cap upper-cases a
   single letter. `TestSurfKeysAreDistinct`: no two bindings of different
   commands read the same.
3. **`:mark` listing four, the old five.** The commands did not change:
   `matchCommands`, `fuzzyScore`, `paletteRows` and `paletteTitle` have no
   diff since aca330e. The old shot's fifth row, `doc.reload`, was the
   query `ark`: the shot's typing dropped the `m` (wtype's first keys). With
   the typing slowed (`-d 150`), the old and the new both list four for
   `:mark`. The shots here are of the same query.
4. **The first panel's rule.** Present in all three; in dense it was a 1 px
   hairline against a selected first row, and the crop hid it. In Compact it
   has its margin and shows in each.
5. Also, from the old palette: its "1–7 of 28" range, which the cells had
   and the host table had a scrollbar for, is back as a muted count beside the
   query (`Palette.Range`); there is still no scrollbar (G5).
6. The hosts' caps are kept (`hotState.caps`), and each surf surface's
   Platform is set from them (`ready()` was never called before).
