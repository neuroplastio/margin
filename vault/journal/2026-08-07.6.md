## What changed

Drained `vault/feedback/2026-08-07-command-palette.md`. It asks for `:` to open
a command palette, but explicitly names its own prerequisite: `handleKey`
matched raw key strings in a `switch`, which means a palette selecting a
command and a key pressing it would be two different code paths — precisely
what requirement 2 ("the palette is a way *in*, never a second
implementation") rules out. The feedback's own suggested split lists that
registry as worth doing on its own, even if the palette slips.

The board's `Awaiting review:` is still set to PARSE-02, so only `[mech]` work
is allowed this leg. The registry is mechanical — it changes no key's
behaviour and nothing on screen — but everything else the feedback asks for
(`:` opening anything, where a palette sits, ranked vs. stable ordering,
staged value commands) is a new interaction with real unsettled questions
attached to it (see its own "Not settled" section). So this leg is **only**
the registry: `internal/review/command.go`.

**The registry.** Every verb margin performs — `move.down`, `move.up`,
`move.first`, `move.last`, `comment.new`, `comment.edit`, `mark.reviewed`,
`mark.flagged`, `mark.cycle`, `review.export`, `app.quit` — is one `command`:
a stable dotted id, a description, an `Applicable(m) bool` guard, and a
`Run(m) tea.Cmd`. `keymap` is the one place a raw key string resolves to a
command id. `handleKey` is now just:

```go
id, ok := keymap[msg.String()]
if !ok {
    return nil
}
cmd, ok := commandByID(id)
if !ok {
    return nil
}
return cmd.Run(m)
```

Every `Run` body is the old switch case moved verbatim — same guard, same
status message, same return. `ctrl+\` stays outside the registry: it is the
host's own escape hatch for a wedged composer child, not a document-review
verb, and `interaction.md` already documents it as the one key the host
intercepts unconditionally.

**`Applicable` is metadata, not a gate.** `handleKey` does not consult it —
each `Run` already carries the guard that produces the original status
message ("nothing to comment on here", etc.), and re-checking `Applicable`
first would just swallow that message, which is a behaviour change the leg
is not supposed to make. It exists for CMD-04 (focus-sensitive listing) to
read from later.

## What this deliberately does not do

No `:` key, no palette UI, no filtering, no ranking, no staged commands. The
feedback's own "Not settled — needs judging on a screen" section (where it
appears, how much it covers, ranked vs. stable order) is exactly the kind of
thing this project asks an agent not to guess at. Split the remaining work
onto the board as CMD-02 through CMD-05 (see `board.md`) so the split is
visible rather than re-derived from the feedback file every time.
