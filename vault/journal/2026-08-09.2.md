## What changed

Since ID-01 landed and blocks now carry durable anchor IDs, an agent can explicitly lookup `.margin/threads/<docPath>/<id>.md` to reply or resolve threads. However, `locator()` wasn't exposing the anchor ID when the block had a valid line number, leaving the agent blind to the ID and unable to reply correctly using file tools.

1. Updated `locator()` in `internal/review/export.go` to include the anchor ID in parentheses, e.g. `## spec.md:12 (^0afa31)`.
2. Added a short "**Agent instructions:**" preamble at the top of the exported review. This tells any agent reading the export exactly where the thread files are (`.margin/threads/...`), how to match them to the anchor ID provided in the headers, and how to resolve a thread (`resolved: true` in the frontmatter).

These two small changes give an agent both the context (the wording/shape of the prompt) and the means (the locator ID) to close the loop autonomously using standard file edits, meeting the M2 persistence requirement.
