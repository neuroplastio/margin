## What changed

Implemented staged value commands for the command palette (Requirement 5 & 6 from the command-palette feedback).
- Extended the `command` registry struct to support a `Values` function. If provided, the command accepts a string value and selecting it in the palette transitions into a "value stage" rather than executing immediately.
- Changed the `Run` signature to accept `val string`.
- Updated `paletteRows` to parse the query and filter by the command's available values when a command is staged (i.e. `m.paletteQuery` starts with `cmd.ID + " "`).
- Pressing `Backspace` on an empty value (i.e. when `m.paletteQuery == cmd.ID + " "`) rewinds out of the value stage back to the main command list.
- A staged command's keybinding now opens the palette partway through (seeded with `cmd.ID + " "`) instead of running instantly, saving the user from having to type the command name.
- Added two staged commands to the registry to prove the feature:
  - `mark`: (values: `reviewed`, `flagged`) mapped to `m`.
  - `goto`: (values: document heading names) mapped to `s`.

## Verification

`make check` and `make test-race` both pass.

## Demo

```bash
go run ./cmd/margin testdata/sample.md
```

1. Press `m` (or type `:mark `). The palette should open partway through, showing `mark ` in the input and listing `reviewed` and `flagged` as options.
2. Press `Down` and `Enter` on `reviewed` to apply the mark.
3. Press `s` (or type `:goto `). The palette should list the headings of the document.
4. Press `Backspace` immediately. The input should rewind to `goto` and show the main command list.
5. Press `Esc`. The palette should close without doing anything.
