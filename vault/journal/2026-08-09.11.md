# 2026-08-09.11 — a bogus Co-Authored-By trailer attributed four commits to a stranger

Kind: mechanical (history repair + instruction hardening; nothing felt)
Task: maintainer override — "why is a random user a coauthor?" on
`bfba843`; fix history and remove the instruction that produced it
Commit: (this one)

## What happened

Four commits carried `Co-Authored-By: Antigravity <antigravity@google.com>`
(or a bare `Co-Authored-By: antigravity`) in their trailers:

- `e57dc60` feat(thread): delete thread with confirmation
- `4036b38` feat(export): add agent instructions and anchor IDs
- `7b2eeb3` feat(scroll): mouse wheel support (SCROLL-03)
- `bfba843` feat(scroll): hover effects

GitHub renders a `Co-Authored-By:` trailer by resolving its email against
registered accounts, so `antigravity@google.com` attributed every one of those
commits to whoever registered that email — a GitHub user named shimoneator.
The maintainer found it, flagged it as an urgent override, and asked for the
history to be rewritten and force-pushed, and for the instruction that produced
the trailer to be removed.

## The root cause

The instructions said "end commit messages with the standard `Co-Authored-By`
trailer" (AGENTS.md/CLAUDE.md, and the do-leg skill). "Standard" was never
defined as the maintainer's identity, so a tool's own platform identity —
`Antigravity <antigravity@google.com>` — qualified as a trailer and went in
verbatim. The identity resolved on GitHub to a third party, not to the tool or
the maintainer.

## What changed

1. **History rewrite.** `git filter-branch --msg-filter` stripped the two
   trailer shapes from exactly those four commits, nothing else. Verified every
   one of the 83 rewritten commits has a byte-identical tree to its original
   (`git rev-parse $h:` equal before/after), that all 83 are accounted for, and
   that no `antigravity` trailer remains on `main`. Original objects are still
   in the object store and a local `backup-pre-antigravity-fix` branch points at
   the pre-rewrite tip (`67fe6f2`) — the old history is one force-push away.
   Force-pushed with `--force-with-lease`.

2. **The instruction is now pinned.** AGENTS.md (a symlink to CLAUDE.md) and the
   do-leg skill now say: end every commit with exactly
   `Co-Authored-By: Anatoly Rugalev <anatoly.rugalev@gmail.com>` and nothing
   else in the trailer block — never a tool's own platform identity.

## The hard rule this lands as

A `Co-Authored-By:` whose email belongs to anything other than the maintainer
resolves on GitHub to whoever registered that email. That is a remote property
the committing agent cannot see, so the only safe trailer is the maintainer's
identity, verbatim. Recorded in D8's section and in the hard rules.

## Verification

- `make check` green.
- 83/83 commits accounted for; 0 tree diffs across the rewritten history.
- `git log origin/main | grep -i antigravity` → nothing.

## Note

The pre-existing trailer convention (D8) said agent involvement is disclosed
with `Co-Authored-By:`. That decision is unchanged in intent — the trailer still
names the co-author — but the instruction now makes the *identity* non-negotiable.
