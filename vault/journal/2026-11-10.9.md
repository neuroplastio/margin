# 2026-11-10.9: OSC 8 hyperlinks in the cells' document column

Kind: felt (what a link looks like and does in the terminal).
Task: the maintainer's request of 2026-11-10: "Add external links - I expect
them to be OSC8 - both to local files and web urls."
Commit: (this one)
Agent: Margin Agent on Claude Code.

## What changed

- `links.go`: a link in the cells' prose (paragraphs, list items, quotes,
  table cells) is an OSC 8 hyperlink around each of its words. A web link
  (`http`, `https`, `mailto`) goes as it is. A local path goes as a `file://`
  URL: from the document's directory, or from the review root for a leading
  `/` (as `followDoc` resolves it), the fragment kept. A `#fragment`-only link
  has none: margin follows it with ctrl+]. Other schemes (`javascript:`, `ftp:`)
  have none.
- The link target rides the inline runs (`glueWords` copied only `link` before)
  and `drawBody` takes a `linkBase` (the document's directory and the review
  root) from the model; `wrapInline`, `wrapList`, `wrapQuote`, `padCell`,
  `tableRowLine` and `renderTable` take it as a trailing argument that older
  callers may leave out.
- One hyperlink per word, written with `ansi.SetHyperlink`; lipgloss's
  `Style.Hyperlink` wrapped every character of an underlined run on its own.
- The demo document has a "Links out of the document" section: a web link, two
  files beside it and above it, one from the review root, and a heading link.

## Decided (the open question)

In-tree `.md` links get an OSC 8 too: ctrl+] follows them in margin, and the
terminal opens the same link as a file. Easy to take out (`linkBase.url`).

## Not done

- Links in a comment (surfmd) are text only; surfmd's links are surf's `link`
  runs, which carry `Run.Href` into the cells themselves (handoff A2/B5), so
  that may already be a hyperlink: untested, on the list.
- On a host the prose blocks' links are as before (`target=_blank` for web
  links, a click on a local one is margin's).
