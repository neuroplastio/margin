## What changed

Addressed feedback in `vault/feedback/2026-08-09-additional-ux-and-cli-feedback.md`:
- Focused comment rendering in `appendComments` (`internal/review/review.go`) no longer places the `focusStyle` ("▌ ") focus bar on the author header line (`head`). The author header line now consistently starts with `"  "` and retains standard `authorStyle` and `dimStyle`.
- When a comment is focused (`m.at.comment == j`), each line of the comment body text is prepended with `focusStyle.Render("▌ ")` and styled with `focusStyle` (pink/magenta color 212), so the comment body text itself is clearly highlighted and marked as focused.
