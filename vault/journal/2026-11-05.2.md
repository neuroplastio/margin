## What changed

- `go.mod`: hotty-surf at 35f857b (a pseudo-version), with cel-lite.
- `internal/review/surfhost.go`: `surfHost` shows a hotty-surf model as one
  of margin's surfaces. It is the model's `surfrun.Runner` and wraps a
  `surfrun.Surface`, the documented route for a host that places surfaces
  itself. Per hotty Agent's recipe:
  - the surface's `Doc` calls `Show`, which the Session asks for only when
    the host has no document; the frame `Show` returns is sent after `Layout`;
  - surf's stylesheet is sent once a session (`hotState.surfCSS`);
  - `Post` goes through the program (`surfPostMsg`); `NoQuit` is set, so a
    surf binding never ends margin; `Program` carries margin's own keys;
  - `Platform` is set from the host's caps on `ReadyMsg`.
- `frame()` is a copy of surftest/hosted.go's frame writer, which is the
  documented host route. hotty Agent will export it as `surfrun.WriteFrame`;
  margin drops its copy then.
- `surfhost_test.go`: a surf counter beside a Session on a hottytest host.
  The document goes once, and two clicks come back as deltas ending in 2.
