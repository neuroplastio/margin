# 2026-08-09.7 — SCROLL-04 (Mouse hover effects)

Added mouse hover effects that highlight the block under the pointer without moving focus.

- Added `hoveredEntry` to the `model` to track the currently hovered block.
- Intercepted `tea.MouseMotionMsg` in `Update` and routed it to `handleMotion`, which hit-tests the pointer coordinates and sets `hoveredEntry`.
- Updated `gutter()` to accept a `hovered` boolean and render a dim `▌` (using a new `hoverStyle`, color `239`) when the block is hovered but not focused. Focus retains the bright `▌` and has priority.

This is a `[felt]` change. The hover indicator is a dim `▌` in the gutter, sharing the same space and glyph as the focus indicator. It gives a visual cue of what the pointer is over without immediately shifting the document's state.

## Demo

```bash
make run
```
1. Move the mouse around the document pane without clicking.
2. A dim `▌` should follow the pointer in the left gutter, highlighting the block currently under the mouse.
3. Click on a block. The dim `▌` should turn bright (focus) and stay on the block.
4. Does the dim `▌` provide enough contrast, or is it too subtle? Does it conflict visually with the focus indicator?
