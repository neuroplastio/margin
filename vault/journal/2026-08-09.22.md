## What changed

Drained `vault/feedback/2026-08-09-visual-mode-range-selection-feedback.md`:

1. **Line/Range Prepending in Comments:**
   - Blocks track both start line (`b.line`) and end line (`b.endLine`), derived from byte offsets during document parsing (`parseDoc` in `parse.go`).
   - When initiating a new comment (`c` / `comment.new`) while a blockwise visual selection (`V`) is active:
     - Multi-line range selection automatically prepends `L<start>-<end>: ` (e.g. `L12-18: `) to the comment draft.
     - Single-line selection automatically prepends `L<start>: ` (e.g. `L12: `) to the comment draft.
     - Visual mode exits upon starting the comment.

2. **Yank Reference (`gy` / `yr` / `selection.yankRef`):**
   - New command `selection.yankRef` ("Yank line reference") registered in the command registry and palette.
   - Bound to key sequences `yr` and `gy`.
   - Copies the line/range locator reference (e.g. `sample.md:L12-18` or `L12-18`) to the clipboard.
   - Status line reports `Yanked reference <ref>`.

## Demo

```bash
make build && ./bin/margin testdata/sample.md
```

1. `V` on a paragraph, then `j` to select across blocks. Press `c` — the comment editor should open with `L12-18: ` (or appropriate line numbers) pre-populated at the start of the draft.
2. Type a comment after the prefix and submit (`ctrl+enter`). The posted comment displays the line reference prefix in its body, allowing flexible placement anywhere in the review.
3. `V` then `j` to select a range, then type `yr` or `gy` — the status line should display `Yanked reference sample.md:L12-18` and copy `sample.md:L12-18` to clipboard.
4. Without visual mode active, standing on a block and pressing `yr` or `gy` yanks that block's line reference to clipboard.
